# 実機確認

## 前提

- Bitwig Studio 6.0.11以降
- Synthesizer V Studio 2 Proの通常VST3プラグイン
- READMEの手順でControllerスクリプトとSynthesizer Vスクリプトを配置済み

## 基本転送

1. BitwigのArrangerに4小節のMIDIクリップを作成する。
2. C4、D4、E4を異なる開始位置・長さ・Velocityで配置する。
3. クリップを選択し、`python3 bridge/copy_from_bitwig.py`を実行する。
4. 成功メッセージと「3ノートをコピー」のBitwig通知を確認する。
5. 通常VST3版Synthesizer Vを開き、再生カーソルを任意の位置へ移動する。
6. 転送先トラックをピアノロールに表示し、「Bitwig MIDIを貼り付け」を実行する。
7. 再生カーソル位置から3ノートの新規グループが作られることを確認する。
8. 音程、相対開始位置、長さがBitwigと一致することを確認する。

## 安全性

1. 既存の歌詞・調声済みグループがあるプロジェクトで貼り付ける。
2. 既存グループが変更されず、別グループとして追加されることを確認する。
3. 同じデータを再度貼り付け、新しいグループがもう1つ作られることを確認する。

## エラー

- Bitwigでクリップ未選択時にコピーし、エラーになること。
- 空のMIDIクリップ選択時にコピーし、エラーになること。
- 68.27拍を超えるクリップをコピーし、上限エラーになること。
- 通常テキストをクリップボードへ入れてSynthesizer V側を実行し、何も変更せずエラーになること。
- Controllerを外してコピーし、タイムアウトエラーになること。
